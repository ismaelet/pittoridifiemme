# Pittori di Fiemme

A web project dedicated to showcasing historical paintings and artists from **Val di Fiemme**, a valley in Trentino, Italy, with a particular focus on 19th-century art.

The website was developed to provide a digital space for exploring the region's artistic heritage, presenting paintings and information about the artists who created them.

## About the Project

*Pittori di Fiemme* is an archival web project designed to make the artistic heritage of Val di Fiemme more accessible through a simple, structured browsing experience.

The application was built entirely with native web technologies, without relying on external frameworks. It reflects an earlier stage of my development experience and is preserved as part of my professional portfolio.

## Technologies

The project was developed without frontend or backend frameworks, using:

- **PHP** — Server-side logic and dynamic page generation
- **HTML5** — Page structure and content
- **CSS3** — Styling, layout, and responsive design
- **JavaScript** — Client-side interactions

## Project Goals

- Showcase historical paintings associated with Val di Fiemme.
- Present information about the artists and their works.
- Make local artistic and cultural heritage accessible through the web.
- Provide a straightforward browsing experience focused on the artwork.

## Technical Approach

The application follows a traditional server-rendered architecture, with PHP responsible for generating dynamic content and HTML, CSS, and JavaScript handling the presentation and client-side behavior.

Rather than relying on a framework, the project was implemented using the core capabilities of these technologies, providing hands-on experience with fundamental web development concepts.

## Project Status

**Archived / Portfolio Project**

This is an older project preserved for historical and portfolio purposes. It is not under active development, and its architecture and implementation reflect the technologies and practices used at the time of its creation.

## Context

Val di Fiemme, located in Trentino in northern Italy, has a rich cultural and artistic heritage.

This project was created to contribute to the digital presentation of that heritage, with particular attention to paintings and painters associated with the region during the 19th century.
